# InfoRoute Loiret

App mobile native (iOS + Android) d'infos routières en temps réel pour le Loiret (45).

- `app/` : Expo + TypeScript + NativeWind + MapLibre
- `api/` : Node + Fastify + Postgres (ingestion des flux, API REST, push)
- `infra/` : docker-compose, déploiement
- `docs/` : specs et design
- `design/tokens.json` : tokens de design (source de vérité)

Lire `CLAUDE.md` / `AGENTS.md` avant de contribuer.
